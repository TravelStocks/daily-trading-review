Trading Playbook / Board Relay

只在强板块里，接最强身位板。

这套模式的核心不是每天出手，而是等到环境、题材、身位、买点、仓位五件事同时对齐。环境好，敢在爆量弱转强里前置，甚至全仓重仓打强加速；环境差，空仓或板上就走。炸板和情绪变坏时，卖点必须比观点更硬。

板块效应强 持续性板块 强身位板 爆量弱转强 转强确认 炸板直接走 全仓 / 空仓
01 / TARGET 题材内最高、最强、最前排。
02 / ENTRY 爆量弱转强前置，转强确认标准。
03 / EXIT 分歧炸板、板块走弱，直接撤。
RELAY CONTROL BOARD
GO

板块先行，身位跟上

首板或二三板已打出题材效应，涨停家数最好 >= 6，线内有三板以上高标。

WATCH

二板爆量，三板转强

二进三是更舒服的确认点：筛掉一批杂票，再看谁能从分歧里升位。

STOP

龙头排不到，不买次强

做错往往不是方向错，而是退而求其次。后排、低一位、杂毛都容易炸板。

有最强做最强；没有最强，就空着。
01 / DECISION LOGIC

五道门，决定今天能不能接力。

董事长模式的稳定性来自过滤，不来自预测。每一道门都要缩小可交易范围，直到只剩题材内真正有辨识度的强身位。

环境

  • 短线赚钱效应是否有容错
  • 高标是否被杀跌或监管压制
  • 大盘是否支持资金做高度

板块

  • 是否先出现强板块效应
  • 是否是持续性题材，不是一天热闹
  • 涨停家数最好 >= 6

身位

  • 只看题材内最高板、最强板
  • 多线并存时，选有三板以上高标的线
  • 次强、低一位、后排直接剔除

买点

  • 爆量弱转强是买点前置
  • 转强确认是标准买点
  • 环境越差，越需要确认

卖点

  • 分歧炸板直接走
  • 监管红线、情绪转弱主动降风险
  • 做错不加戏，止损后空仓等
02 / MARKET TERRAIN

环境不同，接力层级完全不同。

真正要避开的不是接力本身，而是情绪差时的中位非龙头接力。

CORE RULE

三进四、四进五、五进六，只给真正龙头。

没有特别好的票，没有真正的龙头票，就不做中高位接力。尤其当一鸣食品这类高标被杀、监管压制明显、短线容错变差时，中位接力容易直接爆炸。

非龙头，不接中位

环境差：低位试错

做一进二或二进三，重点看新题材能否打出板块效应。二进三更优，因为已经筛掉一批不够强的标的。

一进二 二进三 不乱接中位

环境好：龙头升位

有高标、有容错、有板块回流预期时，才看三板以上强身位的爆量弱转强和转强确认。

爆量弱转强 转强确认

三板分水岭

二板爆量烂板后，三板缩量转强、弱转强、T字回封，是博弈主升切入的重要节点。

二进三定龙 主升先手

五板分水岭

五板也可以接，但必须板上确认。连续加速不爆量，后面再爆量往往意味着风险释放。

板上确认 防加速末端
03 / ENTRY SYSTEM

两个买点，一个禁区。

董事长的厉害之处，是在关键标的上敢把仓位打够；但他也会在确认失败、炸板或监管压力出现时快速撤。

买点前置

AGGRESSIVE

环境和板块已经走强时，围绕强身位板做爆量弱转强、爆量炸板回封。利新能源、传智教育这类动作，核心是提前拿到关键票仓位。

1板块先打出强效应
2标的是题材前排身位
3分歧爆量后回封，博弈次日转强

标准买点

CONFIRMED

环境不够放松时，等转强确认再打。比如二板爆量烂板后，三板弱转强成功，或者四板极致弱转强再确认参与。

1二板或前一日充分换手
2次日主动转强，不被板块拖垮
3板上确认，避免盘中想象

禁区

NO TRADE

龙头买不到，就退而求其次；题材有热度，就随便找低一位；中位不是最强，却想蹭情绪。这些都不是模式，是亏损来源。

1题材内不是最高身位，不做
2板块效应弱，不做
3高标杀跌压制中位，不做
04 / ACCELERATION & POSITION

强加速的牛，不只是快，是敢在模式里极致切换。

小肉来自隔夜竞价抢加速板，大肉来自扫板打板、板上扫进去。共同前提只有一个：强板块效应下，二板及以上高标升位。

Position Switch

不是建仓、加仓、减仓、清仓，而是全仓和空仓。

他强在仓位管理的极致：环境好、板块强、模式内机会出现时，敢重仓甚至全仓打进去；生态恶劣、A股整体情绪极差、板块或高标不对时，马上走，割肉也果断。不是每天都有仓位，而是只在自己的模式里给仓位。

空仓 环境差、生态恶劣、高标杀跌、模式外诱惑多时，先把自己从市场噪音里拔出来。
↔
全仓 强板块效应 + 二板以上高标升位 + 量能受控 + 情绪支持，才值得重击。

小肉：隔夜竞价抢加速

当题材和高标已经明牌，竞价阶段抢加速板，吃的是强一致的溢价。这类机会反应要快，但必须建立在板块效应和整体情绪允许的前提上。

竞价抢 二板以上

大肉：扫板打板

真正的大肉，多数是在板上扫进去。不是低吸想象，而是在强板块里做高标升位，确认资金态度后把仓位打满。

扫板 打板 高标升位

量能与情绪控制

强加速不是无脑冲。量能、环境、短线情绪、板块持续性都要对齐。环境好时买点前置；环境差时，即使上板也可以板上走。

量能受控 环境差就走

模式少而精

专注做好自己的模式就足够了。模式少而精，才能屏蔽市场噪音和自己的情绪干扰，快速识别机会和陷阱，长期获得概率优势。贪多去学别人的模式，往往要先用大亏去磨合。

少而精 概率优势
05 / CASE LIBRARY

案例不是记股票名，是记当时的条件。

同一只票换个市场环境，结论可能完全不同。这里按模式要素拆解，而不是做事后崇拜。

龙柏传媒

强加速

在强板块效应和情绪支持下敢于打进去，体现模式内机会反应快、仓位敢给。

强加速要敢，但前提是环境、题材、身位、量能都对。

06 / ERROR DISCIPLINE

董事长也会犯错，所以纪律必须写在页面上。

两张截图不是用来证明他永远正确，而是提醒你：强者也会被后排和情绪误伤，区别在于他会很快认错。

错误通常不是看错题材，而是降低了标的标准。

排不到龙头，选择次强；看到题材热，买了低一位；情绪高标杀跌，还去做中位。这些动作会把一个原本清晰的模式，变成随手交易。

  • 龙头买不到，不代表可以买后排。
  • 板块效应弱，单独高度不可靠。
  • 分歧炸板时，卖点优先级高于预期。
  • 亏损后空仓等待，比急着修正更重要。
07 / EXECUTION CHECKLIST

盘中只问这些问题。

把复杂判断拆成固定问题，减少临场被分时、盈亏和情绪牵着走。

买入前

  1. 今天短线环境是否支持接力？
  2. 这个板块是否已经打出强效应？
  3. 它是不是题材内最高、最强、最前排？
  4. 买点是前置，还是确认？
  5. 如果炸板，能不能立刻执行卖点？

持仓中

  1. 板块是否继续回流，而不是只靠单票硬顶？
  2. 是否接近监管红线或异动压力？
  3. 高标是否出现一字闷杀或集体杀跌？
  4. 分歧是良性换手，还是承接失效？
  5. 仓位是否只给了关键标的？

卖出时

  1. 炸板后不要幻想二次转强。
  2. 板块低开回调，高开跳水要先保命。
  3. 不是龙头的票，亏损容忍度更低。
  4. 错了就走，走完再等下一次共振。
  5. 卖飞可以复盘，亏大通常是纪律问题。

仓位与专注

  1. 模式内机会是否值得重仓，而不是随手轻仓试错？
  2. 模式不成立时，是否能直接空仓？
  3. 今天是不是在学太多别人的模式，导致噪音变多？
  4. 是否只做自己最熟的强板块高标升位？
  5. 全仓前，是否已经写清楚失败后的卖点？
可以前置 环境好，板块强，身位真龙头，爆量弱转强或炸板回封。
等待确认 环境一般，板块有效但不够放松，等三板或四板转强确认。
必须放弃 龙头排不到、只剩次强后排，或高标杀跌压制中位。
低位优先 情绪差时做一进二、二进三，二进三更容易确认身位。
中位只给龙 三进四、四进五、五进六，必须是情绪和题材共同认可的龙头。
卖点无条件 分歧炸板、监管压力、板块走弱、情绪杀高标，先走再说。
强加速重击 强板块效应下，二板及以上高标升位，隔夜竞价、扫板、打板才有意义。
全仓/空仓 不是所有行情都要有仓位。模式成立敢重击，模式不成立就空仓。
不贪多 模式少而精，才能屏蔽噪音。贪多学别人模式，往往先亏钱磨合。

仅为个人交易模式复盘与学习整理，不构成任何投资建议。实际交易需结合当日市场环境、流动性、监管变化与自身风险承受能力。
